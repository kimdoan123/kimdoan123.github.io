hypoarena is a friendly workbench that helps you explore scientific ideas, weigh the evidence behind them, and compare them fairly — all on your own computer, with no internet connection required.

🔬 What Is hypoarena?

Imagine you have a notebook full of questions about how the world works. You suspect some answers are stronger than others, but you want proof — a clear, ordered list of which ideas hold up and which ones fall apart. That is exactly what hypoarena helps you do.

hypoarena takes a scientific hypothesis and turns it into a living map. Every idea is connected to the pieces of evidence that support or challenge it, so nothing floats around unattached. Instead of a messy pile of notes, you get a clean, grounded picture of how your reasoning fits together.

Behind the scenes, hypoarena works through three friendly stages: it generates candidate hypotheses, it lets those candidates debate each other by comparing evidence, and it evolves the strongest ideas into sharper versions. Each round produces a ranking you can trust, because the comparison is done using a tournament system that has been proven fair for ranking skills.

Everything runs offline. There are no accounts, no cloud uploads, and no waiting for a server. Your research stays on your machine, and every report you export is reproducible — if you share it with a colleague, they can run the same steps and see the same results.

✨ What You Can Do With It

  • Build hypothesis-evidence graphs. Every hypothesis is pinned to real evidence, so you always know why an idea is being considered.
  • Explore synthetic literature with planted causal chains. Practice on test scenarios where the correct answer is known in advance — perfect for learning how the tool thinks before you point it at your own questions.
  • Run generate-debate-evolve loops. Watch ideas improve over several rounds as they compete, refine, and sharpen.
  • Plug in offline adapters. Choose from interchangeable adapters that keep the whole workflow local and private.
  • Hold Elo-style tournaments. Hypotheses face off in pairwise comparisons, and the ranking that emerges reliably recovers the correct order of skill — even when the differences are subtle.
  • Clean up duplicates automatically. Paraphrase detection merges hypotheses that say the same thing in different words, so your final list is tidy and not repetitive.
  • Accumulate evidence the Bayesian way. Each new piece of evidence updates the confidence in a hypothesis gradually and transparently, rather than jumping to a conclusion.
  • Export reproducible reports. Get a clear, shareable summary of what you tested, what won, and why.
hypoarena is built on a lightweight numerical core and runs comfortably on a normal CPU. An optional extra package adds accelerated processing if you happen to have a compatible graphics card, but it is never required.

🧭 Your First Session, Step by Step

Once hypoarena is running, the flow is deliberately simple. You will not be dropped into a blank screen with no guidance.

  1. Pick a starting scenario. The included synthetic literature comes with known causal chains, which means the tool already knows the right answer. This is the safest way to see the system work before you trust it with your own question.
  2. Choose an offline adapter. Adapters are the interchangeable engines that propose and refine ideas. Select one from the list; you can swap it later without starting over.
  3. Set the number of rounds. A small number of rounds gives a quick preview. More rounds give the debate time to sharpen the hypotheses. Start small — three rounds is plenty for a first look.
  4. Start the run. hypoarena generates candidate hypotheses, links each one to the evidence it used, and begins the debate and evolution cycle.
  5. Review the tournament. When the run finishes, you get a ranked table. Each hypothesis shows its tournament score and its accumulated evidence, so you can see both how it performed and why.
  6. Export the report. Save the results as a clean summary you can read later, print, or share with a collaborator.

If you want to confirm the system is behaving correctly, compare the final ranking against the planted order in the synthetic scenario. When the recovered order matches the planted one, you know everything is wired up properly.

📊 Understanding the Reports

The report is where hypoarena earns its keep. It is written to be readable by someone who has never seen the tool before.

  • The evidence map shows each surviving hypothesis with the evidence attached to it. Nothing is listed without a reason.
  • The score table ranks hypotheses from strongest to weakest based on the tournament, not on guesswork.
  • The confidence trail records how belief in each hypothesis shifted as evidence accumulated, round by round.
  • The duplicate log notes which near-identical hypotheses were merged, so you can see the cleaned-up result without losing track of what happened.
  • The run settings capture every choice you made, which is what makes the report reproducible. Run it again with the same settings and you get the same answer.

Reports are plain files stored on your own computer. There is no automatic syncing and no hidden upload.

You do not need to write any code. You do need a normal Windows computer, some free disk space, and a little patience the first time you follow the setup steps.

🛠️ Troubleshooting Common Hiccups

The download will not start. Try a different browser. Some browsers block downloads from unfamiliar pages until you confirm you trust the source.

Windows warns you about the file. Windows protects you from files it has not seen before. Choose to keep the file if you are confident it came from the official link above, then extract it as usual.

The extracted folder looks empty. You may have opened the compressed file instead of the extracted folder. Right-click the downloaded file and choose Extract All… again, then open the newly created folder.

Nothing happens when you follow the startup instructions. Close the window and try again, making sure you are inside the extracted folder and not inside a subfolder. Copying the command exactly as written in the included text file avoids most problems.

It feels slow on long runs. Reduce the number of rounds. Fewer rounds complete faster, and you can always re-run with more rounds once you are happy with your settings.
